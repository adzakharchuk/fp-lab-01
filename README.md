# Лабораторна робота №1. Основи функціонального програмування у Python

## Варіант №5: Бронювання готелю
* **Вхідні дані:** бронювання готелю з полями `id`, `nights` (кількість ночей), `price_per_night` (ціна за ніч), `room_type` (тип номера) та `status` (статус замовлення).
* **Основне завдання:** обчислити вартість проживання, сезонну/тривалу знижку та туристичний збір.
* **Функціональні вимоги:**
  1. Реалізовано чисте обчислювальне ядро без побічних ефектів (`print`, глобальний стан, системні виклики).
  2. Всі вхідні структури є незмінними (створюються нові копії словників `with_total`).
  3. Політики фільтрації за статусом, нарахування знижок та туристичного збору реалізовані через `typing.Callable`.
  4. Використано функцію вищого порядку `make_booking_processor` для створення сконфігурованого конвеєра обробки.
  5. Введення/виведення (I/O) винесено окремо у файл `app.py`.
 
## Структура програми
```text
fp-lab-01/
├── core.py              # Чисте розрахункове ядро (функції без side-effects та глобального стану)
├── app.py               # Оболонка введення/виведення (I/O, консольний друк звіту)
├── requirements.txt     # Залежності проекту (pytest, mypy, black, ruff)
├── README.md            # Опис проекту, структури та інструкція запуску
├── report/              # Звіт до лабораторної роботи
└── tests/     # Маркер тестового пакета
    └── test_core.py     # Модульні автотести (pytest: іммутабельність, референтна прозорість)
```
